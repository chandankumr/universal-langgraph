# 🌍 Universal LangGraph Platform

**Anyone in the world can use your LangGraph with their own keys & GPU!**

## Features

✅ **Bring Your Own API Keys** - OpenAI, Anthropic, Google, Groq, Mistral, Ollama  
✅ **Use Your Own GPU** - Local LLM inference with Ollama  
✅ **Choose Your Vector DB** - Chroma, Pinecone, Qdrant, Weaviate, Milvus  
✅ **One-Click Deployment** - Docker-based, works on any machine  
✅ **Secure** - API keys encrypted, multi-tenant isolation  
✅ **Production Ready** - Authentication, logging, error handling
